# loseyourself1978-blip.github.io

Root GitHub Pages site: company home page of Shenzhen Shangfuhongtai Technology Co., Ltd. (深圳市商富鸿泰科技有限公司) and its apps.

- `app-ads.txt` — authorised ad sellers for AdMob (must stay at the domain root).
- `index.html` — bilingual (EN / 简体中文) company home page, used as the App Store marketing URL and as the organization website for Apple Developer enrollment. A `CNAME` file for the company domain will be added once the domain is registered.

Project pages such as `/CoinBounce/` and `/tianma-work-os/` are served from their own repositories and are not affected by this one.
